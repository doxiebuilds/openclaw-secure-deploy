adding a new one past the cap, retire the lowest-confidence or
stalest entry.

Consolidation happens periodically (weekly, or triggered when a
cycle plateaus — see GOALS.md), not every cycle: review recent
MEMORY-<slug>.md entries, look for a pattern that's shown up more
than once, and either add a new rule here or raise the confidence
count on an existing one. A single incident is not a lesson yet —
it's a data point. Two or more of the same failure is.

Format per entry:

  ### <short rule, stated as an instruction>
  Confidence: seen N times
  Last relevant: <date>
  Because: <the actual pattern, one line>

No example entry is included on purpose. A worked example here reads as
a real, already-confirmed lesson once this file is instantiated — with a
plausible date and confidence count attached — and the whole point of
this file is that everything in it was actually observed. Start empty.
